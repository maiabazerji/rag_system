# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report vulnerabilities privately via GitHub's
[private vulnerability reporting](../../security/advisories/new)
("Security" tab → "Report a vulnerability").

Include steps to reproduce, affected version/commit, and impact. You can
expect an acknowledgement within 7 days.

## Scope

This is a self-hosted project. Never commit real API keys or credentials;
configure them through environment variables (see `.env.example`).
